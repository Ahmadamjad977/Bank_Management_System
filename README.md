# Bank Management System (C++)

## Description
This is a simple Bank Management System project built in C++.
It allows users to manage accounts and transactions using file handling.

## Features
- Create new account
- Deposit money
- Withdraw money
- View account details
- Transaction history stored in file

## Files Included
- main.cpp / source code files
- account handling logic
- transaction records (file handling)

## Note
This project is for learning purposes and demonstrates basic file handling in C++.

## How to Run
1. Compile the code:
   g++ main.cpp -o app

2. Run:
   app.exe
